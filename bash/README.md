# Bash-скрипты

| Скрипт | Что делает |
| --- | --- |
| [clean_old_logs.sh](clean_old_logs.sh) | удаляет `.log` старше N суток (по умолчанию 3); `-n` — пробный запуск без удаления |
| [top_files.sh](top_files.sh) | N самых больших файлов в каталоге (по умолчанию 3) с размером в K/M/G |

Примеры:

```bash
./clean_old_logs.sh -n /var/log/myapp 7   # показать, что удалилось бы
./clean_old_logs.sh /var/log/myapp 7      # удалить логи старше недели
./top_files.sh ~/Downloads 5              # пять самых больших файлов
```

Что отработал на них:

- аргументы со значениями по умолчанию: `${1:-.}`, проверка чисел через `[[ =~ ]]`;
- ранний выход с кодом ошибки (`exit 1`, `exit 2`) и вывод ошибок в stderr (`>&2`);
- `find` с `-maxdepth`, `-type f`, `-mmin`, `-printf`;
- безопасная работа с именами с пробелами: `-print0` + `mapfile -d ''` + массив;
- пробный запуск (`-n`) перед удалением;
- конвейер `sort -rn | head | numfmt`.
