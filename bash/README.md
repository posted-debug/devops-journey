# Bash-скрипты

| Скрипт | Что делает |
| --- | --- |
| [clean_old_logs.sh](clean_old_logs.sh) | удаляет `.log` старше 3 дней, выводит список и количество; «Удалять нечего», если пусто; код 1, если нет папки |
| [top_files.sh](top_files.sh) | три самых больших файла в папке с размером; код 1, если нет папки |

Что отработал на них: ранний выход через `if [ ! -d ]` и `exit 1`, вывод ошибок в stderr (`>&2`),
результат `find` в переменной, проверка пустоты `[ -z ]`, удаление через `find -delete`.
