# Bash-скрипты

| Скрипт | Что делает |
| --- | --- |
| [clean_old_logs.sh](clean_old_logs.sh) | удаляет `.log` старше N суток (по умолчанию 3); `-n` — пробный запуск без удаления |
| [top_files.sh](top_files.sh) | N самых больших файлов в каталоге (по умолчанию 3) с размером в K/M/G |
| [check_disk.sh](check_disk.sh) | проверяет разделы и предупреждает, если какой-то заполнен на N% и больше (по умолчанию 80); код 1, если есть проблемы |
| [backup_dir.sh](backup_dir.sh) | упаковывает каталог в `.tar.gz` с датой в имени; второй аргумент — куда сохранять (по умолчанию `.`) |

Примеры:

```bash
./clean_old_logs.sh -n /var/log/myapp 7   # показать, что удалилось бы
./clean_old_logs.sh /var/log/myapp 7      # удалить логи старше недели
./top_files.sh ~/Downloads 5              # пять самых больших файлов
./check_disk.sh                           # проверка с порогом 80%
./check_disk.sh 50                        # разделы, заполненные на 50% и больше
./backup_dir.sh ~/my_project ~/backups    # архив ~/backups/my_project_<дата>.tar.gz
./backup_dir.sh /etc/nginx ~/backups      # бэкап конфигов nginx
```

Что отработал на них:

- аргументы со значениями по умолчанию: `${1:-.}`, проверка чисел через `[[ =~ ]]`;
- ранний выход с кодом ошибки (`exit 1`, `exit 2`) и вывод ошибок в stderr (`>&2`);
- `find` с `-maxdepth`, `-type f`, `-mmin`, `-printf`;
- безопасная работа с именами с пробелами: `-print0` + `mapfile -d ''` + массив;
- пробный запуск (`-n`) перед удалением;
- конвейер `sort -rn | head | numfmt`;
- `set -euo pipefail` — скрипт падает на первой ошибке и на неопределённой переменной;
- разбор вывода `df -P` через `awk` и `while read` с подстановкой процесса `< <(...)` — чтобы счётчик не потерялся в подоболочке;
- `${use_pct%%%}` — отрезать `%` средствами bash, без `sed`/`tr`;
- `tar -C` — чтобы в архиве не было полного пути; `realpath` — чтобы `.` и `dir/` давали нормальное имя архива.
