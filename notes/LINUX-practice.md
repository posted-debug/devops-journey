# Linux на практике — карточки

Вопросы на понимание: ловушки, ошибки, однострочники.

## Права и umask

Скрипту поставили права 711. Сможет ли его запустить кто-то кроме владельца? :: Нет: bash должен прочитать скрипт, нужно r + x. Правильно `755`
Владелец читает и пишет, остальные — ничего :: `chmod 600 file`
Какой umask даст каталогам 750 и какие права тогда получат новые файлы? :: `umask 027`; файлы `640` (666 без битов 027)
Почему `touch` никогда не создаёт файл с правом x? :: Новые файлы считаются от 666, а не от 777
Что на каталоге даёт право r, а что x? :: r — увидеть список имён (`ls`), x — зайти (`cd`) и обращаться к файлам внутри

## Кавычки и подстановки

Чем отличаются `echo "*.log"` и `echo *.log`? :: В кавычках выведется буквально `*.log`, без кавычек bash подставит имена файлов
Какие символы остаются особыми внутри двойных кавычек? :: `` $ ` \ ! `` — остальное буквально, глоб не раскрывается
Что выведет `X=5; echo '$X' "$X"`? :: `$X 5`
Почему `find . -name *.log` может найти не то? :: bash сам раскроет `*.log`, если в текущей папке есть .log-файлы. Нужно `'*.log'`
Найди ошибку: `NAME = "posted"` :: Пробелы вокруг `=`. Правильно `NAME="posted"`
Бэкап `app.conf` одной короткой командой :: `cp app.conf{,.bak}`

## Потоки и логика

Записать и вывод, и ошибки команды в `all.log` :: `cmd > all.log 2>&1`
Куда уйдут ошибки в `cmd 2>&1 > file`? :: На экран: `2>&1` срабатывает раньше, чем stdout ушёл в файл
Что станет с file после `sort file > file`? :: Пустой файл: `>` обнуляет его до того, как sort начнёт читать
Что выведет `false && echo A || echo B`? :: `B`
Что выведет `true || echo A && echo B`? :: `B`: слева направо, `true || echo A` успешно, значит срабатывает `&& echo B`
Найди ошибку: `[ -d "$D" ] || echo "нет папки"; exit 1` :: `exit 1` выполнится всегда. Нужно `|| { echo "нет папки"; exit 1; }`
Почему `cd /nope; rm -rf *` опасно? :: `cd` упадёт, а `rm` удалит всё в текущей папке. Нужно `&&`
Число строк в файле — только число, без имени файла :: `wc -l < file`

## find

Порядок аргументов find и grep :: `find ГДЕ УСЛОВИЯ`, `grep ЧТО ГДЕ`
`-mtime +3` найдёт файлы старше скольки суток? :: 4 и больше: дни округляются вниз, нужно «больше трёх». Строго старше 3 суток — `-mtime +2`
Только .log в текущей папке, без подпапок :: `find . -maxdepth 1 -type f -name '*.log'`
Что сделать перед `find ... -delete`? :: Запустить тот же find без `-delete` и посмотреть список
`ls -l` для каждого найденного .conf :: `find . -name '*.conf' -exec ls -l {} +`
Файлы больше 100 МБ во всей системе, без мусора ошибок :: `find / -type f -size +100M 2>/dev/null`

## grep

Строки, где нет INFO :: `grep -v INFO file`
Только имена файлов с ERROR, рекурсивно по папке :: `grep -rl ERROR dir/`
Строки, которые заканчиваются на .conf :: `grep '\.conf$'` — точку экранируем
`grep -c` считает строки или совпадения? :: Строки: два ERROR в одной строке — это 1

## awk, sort, uniq, cut

Топ-3 IP в access.log (IP — первое поле) :: `awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -3`
Почему перед uniq нужен sort? :: `uniq` схлопывает только соседние повторы
Сколько запросов с кодом 500 (код — 9-е поле)? :: `awk '$9 == 500' access.log | wc -l`
Пути (7-е поле) с кодом 404, без повторов :: `awk '$9 == 404 {print $7}' access.log | sort -u`
Сумма 10-го поля по всему файлу :: `awk '{s += $10} END {print s}' file`
Имена пользователей из /etc/passwd :: `cut -d: -f1 /etc/passwd` или `awk -F: '{print $1}' /etc/passwd`

## sed

Заменить все 8080 на 9090 в app.conf прямо в файле, с бэкапом :: `sed -i.bak 's/8080/9090/g' app.conf`
Конфиг без комментариев и пустых строк :: `sed '/^#/d; /^$/d' app.conf`
Строки 10–20 файла :: `sed -n '10,20p' file`
Заменить /var/log на /opt/logs :: `sed 's|/var/log|/opt/logs|g' file` — другой разделитель, чтобы не экранировать слеши

## Скрипты

Первая строка скрипта и как сделать его исполняемым :: `#!/bin/bash` и `chmod +x script.sh`
Найди ошибку: `if [-z "$F"]; then` :: Нет пробелов внутри скобок: `[ -z "$F" ]`
Выйти из скрипта с ошибкой, если нет папки `$D` :: `if [ ! -d "$D" ]; then echo "нет $D" >&2; exit 1; fi`
Почему `rm -rf "$FILES"` не удалит список путей из find? :: В кавычках это один аргумент со всеми путями сразу. Удалять тем же `find ... -delete`
Проверить синтаксис скрипта / показать каждую команду при выполнении :: `bash -n script.sh` / `bash -x script.sh`

## Процессы

PID nginx так, чтобы не попал сам grep :: `pgrep nginx` или `ps aux | grep '[n]ginx'`
Чем `kill PID` отличается от `kill -9 PID`? :: SIGTERM процесс может обработать и завершиться аккуратно, SIGKILL — нет. Сначала всегда обычный kill
Процесс в состоянии Z — что это, поможет ли `kill -9`? :: Зомби: уже завершился, родитель не забрал код возврата. kill не поможет, дело в родителе
Что реально занято памятью: VSZ или RSS? :: RSS

## Устройства и диски

Что такое `/dev/sda` и сколько он весит? :: Дверь от ядра к диску: места не занимает, через него читаются все байты диска
Файл ровно 50 МБ из нулей :: `dd if=/dev/zero of=f.img bs=1M count=50`
Диски, разделы и куда они смонтированы :: `lsblk`
Подключить sdb1 в /mnt/usb и отключить :: `sudo mount /dev/sdb1 /mnt/usb`, потом `sudo umount /mnt/usb`
`umount` пишет «target is busy» — почему? :: Кто-то находится в этой папке, часто ты сам после `cd`

## Терминал

В начало и в конец строки :: `Ctrl+A` / `Ctrl+E`
Удалить слово слева / всё до начала строки :: `Ctrl+W` / `Ctrl+U`
Подставить последний аргумент прошлой команды :: `!$`, например `mkdir long_name && cd !$`
